## 판정

**검증용 알파 배포: 조건부 가능 / 일반 사용자용 또는 상용 출시: 불가**

## 이번 버전에서 실제 수정한 사항

1. CSV의 NaN, Infinity, 극단적 timestamp를 분석 전에 거절해 HTML/JSON 단계에서 예외가 발생하지 않도록 했습니다.
2. `/robot1/...`과 `/robot2/...` 같은 명시적 토픽 접두어를 탐지한 이벤트에 보존하여, 동일한 bag 안에서 서로 다른 로봇 장애를 임의로 연결하는 위험을 줄였습니다.
3. 미지원 메시지 타입을 본문 분석에 포함하지 않았음을 경고에 명시해 보고서의 적용 범위를 알 수 있도록 했습니다.
4. 설치 및 브라우저 업로드 회귀 검증을 위한 테스트 스크립트를 추가했습니다.

## 출시 전 반드시 해결할 항목 (P0)

- 제조사/사용자 허락을 받은 **서로 다른 실제 ROS2 bag 3개 이상**으로 정확성 확인. 특히 Nav2, 도킹, 비상정지, 안전정지 시 오탐 가능성 검토.
- ROS2 Humble/Jazzy 이상에서 기록된 DB3·MCAP을 각각 테스트하고, 압축(zstd/lz4) 여부·MCAP embedded schema·IDL 지원 범위를 명확히 표시.
- 로봇의 `/cmd_vel`을 실제 구동 명령과 혼동하지 않게 안전정지·속도 제한·프레임, 센서 시간과 녹화 시간 차이를 함께 검증.
- `metadata.yaml`과 분할 bag 입력, 수 GB 규모 로그의 메모리 사용량·업로드 방법 검토.
- 신뢰할 수 없는 파일을 분석할 때의 자원 제한·분리 실행(현재 웹서버는 개발용이며 인터넷 공개 금지).
- 명시적 비식별화/동의: 고객 로그는 회사 기밀 및 개인정보가 들어 있을 수 있으므로 익명 통계만 받는 방식부터 시작.

## 실제 해외 엔지니어 테스트 합격 기준 (제안)

참가 조건: 현업 ROS2 기반 로봇 소프트웨어·통합·운영 엔지니어 5명. 회사·고객사의 허가받은 로컬 데이터 또는 자체 수집 데이터를 사용하며, 원본 bag 파일 공유를 요구하지 않음.

- 5명 중 4명 이상이 별도 실시간 도움 없이 10분 내 설치부터 첫 분석 보고서 열기까지 완료
- 5명 중 4명 이상이 자동 토픽 선택 또는 수동 매핑 방법을 이해
- 5명 중 3명 이상이 실제 장애 분석 워크플로에서 유의미한 시간 절약을 보고
- 실측 재현 가능한 사례 중 주요 사건의 탐지 누락/오탐 목록을 기록하고 원인 분석
- 5명 중 최소 1명이 **실제 유료 파일럿 구매 의사** 또는 구체적 예산·구매 권한 보유를 확인 (의향과 결제 완료는 별도로 표시)
